Install

Homebrew (macOS / Linux, amd64 + arm64):

brew install Blackman99/tap/renewhunt
brew upgrade renewhunt   # after a new release

The formula lives in Blackman99/homebrew-tap and is updated automatically on every release.

Or with Go 1.22+ via go install, or download a static binary (CGO disabled) from Releases.

go install github.com/Blackman99/renewhunt/cmd/renewhunt@latest
renewhunt -version

Release assets cover linux / darwin / windows × amd64 / arm64 via GoReleaser.

# example
curl -sL https://github.com/Blackman99/renewhunt/releases/download/v0.2.0/renewhunt_0.2.0_linux_amd64.tar.gz | tar xz
./renewhunt -version
