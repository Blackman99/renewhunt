Usage

Default command runs scan + clients + timers:

renewhunt
renewhunt scan [paths...]
renewhunt scan -system          # also walk /etc/letsencrypt, cron, systemd
renewhunt clients
renewhunt timers
renewhunt -json
renewhunt scan -json ./deploy

Exit code 1 if any finding is BLOCKED; 0 otherwise; 2 on usage/errors.

Example against the fixture corpus:

renewhunt scan ./testdata
# BLOCKED on --days 80, RENEW_DAYS=83, renewBefore: 2160h
# RISKY on renewBefore: 720h, renew_before_expiry=60
