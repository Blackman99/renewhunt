Configuration

No config file in v0.1. Behaviour is controlled by flags and arguments:

  • paths… — files or directories to scan (default .)
  • -system — append common system paths when they exist
  • -json — machine-readable output
  • -check-live hosts — default command only: also probe these hosts (comma-separated, repeatable)
  • -timeout 10s — per-host timeout for live probes
  • -ari — live probes: also fetch the issuing CA's ARI renewal window (RFC 9773); off by default
  • -ari-directory url — ACME directory to use for ARI when the issuer is not Let's Encrypt, Google Trust Services or ZeroSSL (implies -ari)
  • -version — print version

Scan is read-only and needs no network. Live probes only connect to the hosts you name, over TLS, and contact an ACME CA only with -ari: two unauthenticated, read-only GETs (the directory and the certificate's renewalInfo). Client/timer probes shell out to certbot, acme.sh, lego, kubectl, systemctl, and crontab when present; missing tools are skipped with a note.

Skipped directories include .git, node_modules, vendor, and similar. Only text-ish extensions and cron/Dockerfile/Makefile names are opened.
