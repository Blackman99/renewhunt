Configuration

No config file in v0.1. Behaviour is controlled by flags and arguments:

  • paths… — files or directories to scan (default .)
  • -system — append common system paths when they exist
  • -json — machine-readable output
  • -version — print version

Scan is read-only and needs no network. Client/timer probes shell out to certbot, acme.sh, lego, kubectl, systemctl, and crontab when present; missing tools are skipped with a note.

Skipped directories include .git, node_modules, vendor, and similar. Only text-ish extensions and cron/Dockerfile/Makefile names are opened.
